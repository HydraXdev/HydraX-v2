📋 INSTALLATION QUICK START
═══════════════════════════════════════════════════════════════════════════

1. Install PostgreSQL 14+ with TimescaleDB:
   sudo apt-get install postgresql-14 timescaledb-2-postgresql-14

2. Create database:
   sudo -u postgres createdb bitten_db

3. Run schema installer:
   cd /root/HydraX-v2/db/schema
   psql -U postgres -d bitten_db -f 99_all_tables.sql

4. Create application user:
   psql -U postgres -d bitten_db -c "CREATE USER bitten_app WITH PASSWORD 'password';"
   psql -U postgres -d bitten_db -c "GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO bitten_app;"

5. Update connection string:
   DATABASE_URL="postgresql://bitten_app:password@localhost:5432/bitten_db"

6. Verify installation:
   psql -U postgres -d bitten_db -c "\dt"
