# HYDRASOCKET v1 Disaster Recovery Playbook

## Overview
This playbook covers backup, restore, and cold-start procedures for HydraSocket v1.

## Backup Procedures

### Automated Daily Backups
```bash
#!/bin/bash
# /opt/hydrasocket/scripts/backup.sh

DATE=$(date +%Y%m%d)
BACKUP_DIR="/opt/hydrasocket/backups"
DB_PATH="/root/HydraX-v2/event_bus/bitten_events.db"

# Create backup directory
mkdir -p "$BACKUP_DIR/$DATE"

# Backup database
cp "$DB_PATH" "$BACKUP_DIR/$DATE/bitten_events_$DATE.db"

# Backup sequence index
python3 -c "
import sqlite3
import json
import time

conn = sqlite3.connect('$DB_PATH')
cursor = conn.execute('SELECT account_id, last_seq FROM account_sequences')
seq_data = {row[0]: row[1] for row in cursor.fetchall()}

with open('$BACKUP_DIR/$DATE/seq_index_$DATE.json', 'w') as f:
    json.dump({
        'timestamp': time.time(),
        'sequences': seq_data
    }, f, indent=2)

conn.close()
"

# Compress backups older than 7 days
find "$BACKUP_DIR" -name "*.db" -mtime +7 -exec gzip {} \;

# Remove backups older than 30 days
find "$BACKUP_DIR" -name "*.gz" -mtime +30 -delete

echo "Backup completed: $BACKUP_DIR/$DATE"
```

## Restore Procedures

### Database Restore
```bash
#!/bin/bash
# Restore from specific backup

RESTORE_DATE=$1
if [ -z "$RESTORE_DATE" ]; then
    echo "Usage: restore.sh YYYYMMDD"
    exit 1
fi

BACKUP_PATH="/opt/hydrasocket/backups/$RESTORE_DATE/bitten_events_$RESTORE_DATE.db"
DB_PATH="/root/HydraX-v2/event_bus/bitten_events.db"

# Stop services
systemctl stop hydrasocket
pm2 stop hydrasocket-router

# Backup current database
cp "$DB_PATH" "$DB_PATH.before_restore_$(date +%s)"

# Restore database
if [ -f "$BACKUP_PATH" ]; then
    cp "$BACKUP_PATH" "$DB_PATH"
    echo "Database restored from $BACKUP_PATH"
elif [ -f "$BACKUP_PATH.gz" ]; then
    gunzip -c "$BACKUP_PATH.gz" > "$DB_PATH"
    echo "Database restored from $BACKUP_PATH.gz"
else
    echo "Backup not found: $BACKUP_PATH"
    exit 1
fi

# Verify restore
sqlite3 "$DB_PATH" "SELECT COUNT(*) FROM events;"

# Restart services
systemctl start hydrasocket
pm2 start hydrasocket-router

echo "Restore completed successfully"
```

## Cold Start Procedures

### Complete System Recovery
```bash
#!/bin/bash
# Cold start from backup

echo "🚨 HYDRASOCKET COLD START RECOVERY"
echo "=================================="

# 1. Stop all services
echo "Stopping services..."
systemctl stop hydrasocket
pm2 kill

# 2. Restore database from latest backup
echo "Restoring database..."
LATEST_BACKUP=$(ls -t /opt/hydrasocket/backups/*/bitten_events_*.db* | head -1)
if [ -z "$LATEST_BACKUP" ]; then
    echo "❌ No backup found!"
    exit 1
fi

DB_PATH="/root/HydraX-v2/event_bus/bitten_events.db"
if [[ "$LATEST_BACKUP" == *.gz ]]; then
    gunzip -c "$LATEST_BACKUP" > "$DB_PATH"
else
    cp "$LATEST_BACKUP" "$DB_PATH"
fi

echo "✅ Database restored from: $LATEST_BACKUP"

# 3. Load sequence index
LATEST_SEQ_INDEX=$(ls -t /opt/hydrasocket/backups/*/seq_index_*.json | head -1)
if [ -f "$LATEST_SEQ_INDEX" ]; then
    echo "Loading sequence index from: $LATEST_SEQ_INDEX"
    python3 -c "
import json
import sqlite3

with open('$LATEST_SEQ_INDEX') as f:
    data = json.load(f)

conn = sqlite3.connect('$DB_PATH')
for account_id, seq in data['sequences'].items():
    conn.execute('''
        INSERT OR REPLACE INTO account_sequences (account_id, last_seq, updated_at)
        VALUES (?, ?, strftime('%s', 'now'))
    ''', (account_id, seq))

conn.commit()
conn.close()
print('✅ Sequence index restored')
"
fi

# 4. Initialize missing tables (if needed)
python3 /root/HydraX-v2/test_hydrasocket_migration.py

# 5. Start services
echo "Starting services..."
systemctl start hydrasocket
sleep 10

# 6. Health check
if curl -s http://localhost:8888/healthz; then
    echo "✅ Cold start successful"
else
    echo "❌ Cold start failed - service not responding"
    exit 1
fi

echo "🎯 Cold start complete - system operational"
```

## Backup Retention Policy

### Retention Schedule
- **Daily backups**: Keep for 30 days
- **Weekly backups**: Keep for 3 months (every Sunday)
- **Monthly backups**: Keep for 1 year (first Sunday of month)
- **Yearly backups**: Keep indefinitely

### Storage Requirements
- **Daily**: ~100MB per backup
- **Monthly storage**: ~3GB
- **Yearly storage**: ~36GB

### Backup Verification
```bash
#!/bin/bash
# Verify backup integrity

BACKUP_PATH=$1
if [ ! -f "$BACKUP_PATH" ]; then
    echo "❌ Backup file not found: $BACKUP_PATH"
    exit 1
fi

# Check SQLite integrity
if sqlite3 "$BACKUP_PATH" "PRAGMA integrity_check;" | grep -q "ok"; then
    echo "✅ Backup integrity verified: $BACKUP_PATH"
else
    echo "❌ Backup integrity check failed: $BACKUP_PATH"
    exit 1
fi

# Check record counts
EVENTS_COUNT=$(sqlite3 "$BACKUP_PATH" "SELECT COUNT(*) FROM events;")
SEQ_COUNT=$(sqlite3 "$BACKUP_PATH" "SELECT COUNT(*) FROM account_sequences;")

echo "📊 Backup statistics:"
echo "  Events: $EVENTS_COUNT"
echo "  Sequences: $SEQ_COUNT"
```

## Recovery Time Objectives

### RTO Targets
- **Database restore**: < 5 minutes
- **Cold start**: < 15 minutes
- **Full system recovery**: < 30 minutes

### RPO Targets
- **Data loss tolerance**: < 24 hours (daily backups)
- **Critical events**: < 1 hour (with sequence recovery)

## Disaster Scenarios

### 1. Database Corruption
```bash
# Recovery steps
1. Stop services immediately
2. Restore from latest backup
3. Verify integrity
4. Restart services
5. Trigger portfolio resync
```

### 2. Complete Server Loss
```bash
# Recovery steps
1. Provision new server
2. Deploy HydraSocket code
3. Restore database from backup
4. Configure networking (ports 5558, 5560, 8888)
5. Start services
6. Update DNS/load balancer
7. Verify functionality
```

### 3. Data Center Outage
```bash
# Recovery steps
1. Activate secondary region
2. Restore latest backup
3. Update EA connection endpoints
4. Verify trading operations
5. Monitor for discrepancies
```

## Testing DR Procedures

### Monthly DR Drill
```bash
#!/bin/bash
# Monthly disaster recovery test

echo "🧪 DR DRILL - $(date)"

# 1. Create test restore
TEST_DB="/tmp/dr_test_$(date +%s).db"
LATEST_BACKUP=$(ls -t /opt/hydrasocket/backups/*/bitten_events_*.db | head -1)
cp "$LATEST_BACKUP" "$TEST_DB"

# 2. Verify restore
if sqlite3 "$TEST_DB" "SELECT COUNT(*) FROM events;" > /dev/null; then
    echo "✅ Database restore successful"
else
    echo "❌ Database restore failed"
    exit 1
fi

# 3. Test sequence recovery
python3 -c "
import sqlite3
conn = sqlite3.connect('$TEST_DB')
sequences = conn.execute('SELECT COUNT(*) FROM account_sequences').fetchone()[0]
print(f'✅ Sequence recovery: {sequences} accounts')
conn.close()
"

# 4. Cleanup
rm "$TEST_DB"

echo "✅ DR drill completed successfully"
```
