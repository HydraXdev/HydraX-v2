================================================================================
EXECUTION EXAMPLES
================================================================================

1. OUTCOME TRACKER (Continuous ZMQ Subscriber)
   - Subscribes to port 5560 for real-time market data
   - Tracks active signals (status='ACTIVE') from database
   - Detects TP/SL hits based on bid/ask prices
   - Writes outcomes to signal_outcomes table
   - Example outcome: Signal hits TP → outcome='WIN', pips=+15.0

2. STATS AGGREGATOR (Every 15 Minutes)
   - Queries all users from database
   - Calculates: total_fires, wins, losses, win_rate, total_pips
   - Updates users table with calculated stats
   - Example: User 7176191872 → 45W/15L (75.0% WR, +450.5 pips)

3. FIRESTORE MIRROR (Hourly)
   - Queries PostgreSQL for users/signals/positions updated in last 2 hours
   - Batch writes to Firestore (500 docs/batch)
   - Mirrors 3 collections: users, signals, positions
   - Example: 125 users + 45 signals + 12 positions mirrored

4. RECONCILIATION (Nightly 2 AM UTC)
   - Compares PostgreSQL vs Firestore data
   - Detects missing records and mismatches
   - Auto-corrects simple discrepancies
   - Reports: 5 missing, 2 mismatched, 7 auto-corrected
   - Alerts if >100 discrepancies detected

5. REPORTS (Nightly 3 AM UTC)
   - Pattern performance: Win rates by pattern type
   - User leaderboard: Top 100 by win rate and pips
   - System health: 24h activity metrics
   - Saves all reports to PostgreSQL reports table
